# Perlin Noise
This is a repository implementing Perlin noise. It features n-dimensional Perlin noise, as well as specialized 2 and 3 dimensional Perlin noise. It also features fractal noise for n-dimensions, and once more specialized fractal noise for 2 and 3 dimensions.

## Vector classes
Due to the necessity of vectors for the calculations of Perlin noise, this repository also implements its own vector classes, although they are not the main feature. All vectors are in an orthonormal space. They all support addition of two vectors, multiplication between a vector and a scalar, dot product multiplication between two vectors, finding its length, and normalizing itself.

1. NVector class
   Implements a standard n-dimensional vector in an n-dimensional space.
2. Vector2D class and Vector3D class
   Implements a standard 2-D vector in a 2-D space, and implements a standard 3-D vector in a 3-D space, respectively.

## Noise classes
There are several noise classes in this repository, each featuring different functionalities. They all support seeding through the set_seed() function, which takes in a new seed. They return noise values from the get() function, which takes in the coordinates of the point being asked for.

1. Noise class
   This class implements standard n-dimensional Perlin noise. It uses the NVector class and generates values by taking the coordinates of the point, finding which n-dimensional cube it is in (*if consecutive noise values in the same cube are being searched for the algorithm skips the next step as it caches the previously used vectors, which is a slight optimization*), and passing in the coordinates of each vertex of that cube into a hashing function and getting a value and combining it with the seed; then that value is repeatedly passed into the hashing function to get the coordinates of the vector at that vertex. Once all of the vectors at each vertex are calculated, they are then normalized and those are the vectors that are used to calculate the needed dot products. Once the dot products are calculated they are interpolated using a smoothing function. A few details to keep in mind:
- Since in higher dimensional space it is harder to achieve values near the extrema (-1 and 1), there is a gain applied to the value at the end, which grows logarithmically as the dimensions increase - this gain may overcompensate for higher dimensions, as it is an extrapolation.
- Another thing to keep in mind is that the necessary vectors needed to calculate the noise value in higher dimensions grows exponential (~2^n) which may make calculating higher dimensional noise values very slow or impractical due to the necessary memory needed.

2. Noise2D class and Noise3D class
   These two classes are both made to optimize the speed needed to calculate the noise values in 2-D and 3-D space, as these are the two most common dimensions used in Perlin noise; the two classes implementations are analogous. The algorithm is mostly the same as the one in the Noise class, with the difference that instead of computing the vectors every time a new point is passed in, the algorithm uses a base of pre-computed normalized vectors (256 vectors for 2-D and 512 vectors for 3-D) instead. It works by computing the hash value at each vertex of the square or cube, and then taking its value modulo 256 or 512 for 2-D and 3-D space respectively, to get the index of the normalized vector for that vertex. This drastically reduces the time needed to calculate the noise value, as it eliminates the need for calculating the vectors, which is the most expensive step in the algorithm. Then it calculates the dot products, interpolates the values, and applies a much more accurate gain.

3. FractalNoise class
   This class implements fractal or layered Perlin noise in n-dimensional space; it uses the Noise class to perform its calculations. It does this by taking in 3 additional parameters - octaves, frequency, and amplitude. The octaves determine how many layers the noise will have; the frequency determines how much each additional layer is scaled (or zoomed out); the amplitude determines how much influence each additional layer will have (how much its values are of the original). The frequency and amplitude are applied multiplicatively at each layer. For example if we have octaves = 3, frequency = 4.0, and amplitude  = 0.8, that means that the first layer will have be zoomed out 1.0x, and its amplitude will be 1.0x (no zoom and no change in its value / this is always the case for the first layer), then the second layer will be zoomed out 4.0x, and its amplitude will be 0.8x (4 times more area of the noise, yet its value is only 0.8 of the original), and the third layer will be zoomed out 16.0x and its amplitude will be 0.64x (16 times more area of the noise, yet its value is only 0.64 of the original). **If no additional parameters are passed in, they default to: octaves - 3, frequency - 2.0, amplitude - 0.5.** The noise value is calculated by taking the original coordinates and multiplying them by the frequency at each layer, and then multiplying the resulting value by the amplitude at the respective layer; then these values are added up and divided by the maximum value - the sum of all the amplitudes (for example, using the default parameters the maximum value is 1.75 because the layers have amplitudes of 1.0, 0.5 and 0.25 respectively) - to normalize it. Finally, since the more layers there are the harder it is to get extreme values (-1 and 1), the value is then passed into a smoothing function to stretch the values towards the extrema. **This may cause overcompensation for lower amounts of layers.**

4. FractalNoise2D class and FractalNoise3D class
   These two classes implement specialized 2 dimensional and 3 dimensional fractal or layered Perlin noise to optimize performance for the two most used form of Perlin noise; they use the Noise2D and Noise3D classes to perform their calculations respectively. They work completely analogously to the FractalNoise class.
